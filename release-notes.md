Release 2.1.12 — GT-2 / GT-4 improvements

What's new
• Disconnected state — when no device is connected, only the Status tab is shown with a hint to connect a device. The tab set appears after connecting, according to the device model.
• Status (GT-2 / GT-4) — device name is taken from the REP command (e.g. GT2X).
• Diagnostics (GT-2 / GT-4) — WiFi log channel added.
• System (GT-2 / GT-4) — BLE module update now uses BLE;UPDATE; new "BLE Module Reset" button (BLE;RESET).
• Server (GT-2 / GT-4) — an unconfigured server now defaults to the WiFi channel instead of GSM (these devices have no GSM). The "GT2 Slave" protocol is renamed to "GT2".
