Release 2.1.10 — GT-4 router support, Ethernet settings

What's new
• GT-4 router support. The configurator recognizes the GT-4 by its hardware type and shows the same settings as the GT-2: Status, Diagnostics, Server, WiFi, Ethernet, RS Interfaces and System.
• Ethernet tab (GT-4) — Ethernet on/off, DHCP or static IP, mask, gateway and two DNS servers. Settings can be read from and saved to the device.
• Ethernet status (GT-4) — live connection state (cable, IP assigned, server connected, speed and duplex), MAC address, current IP address, mask, gateway, DNS and DHCP lease time.
• Ethernet settings are included in "Read all", "Write all" and configuration templates.

Changes
• GT-2 — the Ethernet tab is hidden, as this device does not support Ethernet settings.
